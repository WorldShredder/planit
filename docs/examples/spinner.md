> [!IMPORTANT]
> The spinner cycle is tied to the module _log request_ loop speed, which is **1** cycle every **0.1** seconds. You can increase the display duration of each spinner character in multiples of **0.1s** by adding two or more of each spinner character.

`PLAN__STATLOG_SPINNER` takes a space-separated list of characters, each representing a single frame of animation.

```
\ | / -
```
